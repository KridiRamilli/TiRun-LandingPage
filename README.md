# Tirana Run Landing Page

Modern responsive landing page built with Next.js, Framer Motion and CSS.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Replace the logo

Replace:

```text
public/assets/logo-placeholder.svg
```

Keep the same filename, or update the image paths in `src/app/page.tsx`.

## Main assets

- `hero-clean.png` — hero background without left-side text/buttons
- `waitlist-background.png` — Coming Soon background without text/form
- `how-*.webp` — How It Works artwork extracted from the approved mockup
- `route-pin.webp` — route and map-pin artwork
- `app-preview.webp` — PWA screen preview
- `tirana-highlights.webp` — Tirana landmark strip

The hero text, buttons, social proof, phone information cards and the waitlist form are real HTML/CSS elements.
